# Privacy Policy — TEN THOUSAND

_Last updated: 25 September 2026_

**TEN THOUSAND collects nothing.**

That is not a promise about how carefully we handle your data. It is a
statement about the program: there is no code in it that gathers, transmits or
stores anything about you.

## What the app does with data

| | |
|---|---|
| Personal data collected | None |
| Data transmitted off the device | None |
| Advertising | None |
| Analytics or crash reporting | None |
| Third-party SDKs | None |
| Accounts or sign-in | None |
| Android permissions requested | One: VIBRATE (haptic feedback) |

The only thing TEN THOUSAND writes is your save file — your keep and its
buildings, the gear you have found, which heroes and garments you have
unlocked, your best run, and whether sound and rumble are on. It lives in the
app's private storage on your own device. Nobody else can read it, and it
never leaves the phone. Uninstalling the app deletes it.

## Why we can say this so plainly

TEN THOUSAND has no network code at all. It contains no HTTP client, no web
socket, no advertising library, no analytics library and no device identifier
lookup. There is nothing to opt out of, because there is nothing switched on.

It declares exactly one Android permission, VIBRATE, so the phone can buzz
when you are struck, when you rise a level, when the Warlord takes the field
and when a run ends. VIBRATE is a normal permission: it asks you nothing,
reads nothing and reports nothing — it may only run the vibration motor. You
can turn it off in **Keep → Rumble**, and the sound beside it in
**Keep → Sound**.

Everything you see and hear is generated by the program while it runs — the
graphics are drawn in code, the sound is synthesised. The app does not
download content and does not talk to a server.

## Children

Because the app collects nothing, it collects nothing from children either.

## Changes to this policy

If a future version of TEN THOUSAND ever did collect something, this page
would say so before that version shipped, and the change would be visible in
the app's public source history.
