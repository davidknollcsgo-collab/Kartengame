# Privacy Policy — NEKTON

_Last updated: 31 August 2026_

**NEKTON collects nothing.**

That is not a promise about how carefully we handle your data. It is a
statement about the program: there is no code in it that gathers, transmits or
stores anything about you.

## What the app does with data

| | |
|---|---|
| Personal data collected | None |
| Data transmitted off the device | None |
| Advertising | None |
| Analytics or crash reporting | None |
| Third-party SDKs | None |
| Accounts or sign-in | None |
| Android permissions requested | One: VIBRATE (haptic feedback) |

The only thing NEKTON writes is your save file — your colony, its chambers,
your deepest wave. It lives in the app's private storage on your own device.
Nobody else can read it, and it never leaves the phone. Uninstalling the app
deletes it.

You can erase it yourself at any time from inside the game: **Colony → Day →
Found the colony anew**.

## Why we can say this so plainly

NEKTON has no network code at all. It contains no HTTP client, no web socket,
no advertising library, no analytics library and no device identifier lookup.
There is nothing to opt out of, because there is nothing switched on.

It declares exactly one Android permission, VIBRATE, so the phone can buzz when
a raider reaches the brood, when a warden falls, when you fire the burst and
when a session ends. VIBRATE is a normal permission: it asks you nothing, reads
nothing and reports nothing — it may only run the vibration motor. You can turn
it off in **Colony → Day → Settings → Rumble**.

Everything you see and hear is generated by the program while it runs — the
graphics are drawn in code, the sound is synthesised. The app does not
download content and does not talk to a server.

## Children

The app is suitable for all ages and, because it collects nothing, it collects
nothing from children either.

## Changes to this policy

If a future version of NEKTON ever did collect something, this page would say
so before that version shipped, and the change would be visible in the app's
public source history.
